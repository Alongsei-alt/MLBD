# MLBD Car Loan Prediction Project

## Project Overview

This repository contains a machine learning project for the **MLBD course**. The project focuses on predicting whether a customer will repay a car loan based on customer, loan, and vehicle-related information.

The case is based on a car bank, which is usually a subsidiary of a car manufacturer. Since such banks often operate online and may not have a long customer history, assessing the creditworthiness of customers is highly important. The aim of this project is therefore to build a forecasting model that supports loan approval decisions.

## Objective

The main objective of this project is to develop and evaluate a predictive model that answers the following question:

> Can we predict whether a customer will repay a car loan?

The prediction result can help a car bank improve its loan approval process, reduce default risk, and make more data-driven credit decisions.
